# Rechenreise

Ein kleines Rechenspiel für den Browser. Läuft komplett auf dem Gerät, ohne Konto und ohne Server.

Die Hühnerbilder stammen aus Jean Bungartz, „Geflügel-Album“ (1885), Badische Landesbibliothek Karlsruhe, über Wikimedia Commons (Kategorie „Geflügel-Album (Jean Bungartz, 1885)“). Sie sind gemeinfrei und wurden nur verkleinert.

Die Stimme ist einmalig mit ElevenLabs erzeugt (Stimme „Lucy Fennek – Kinderbuch-Vorleserin“) und steckt als Aufnahme in der App. Beim Spielen wird nichts an ElevenLabs oder andere Dienste gesendet.
